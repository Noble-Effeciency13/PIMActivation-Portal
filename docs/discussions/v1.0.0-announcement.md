# PIMActivation Portal v1.0.0 — first public release

The PIMActivation Portal is live.

After running [PIMActivation as a PowerShell module](https://github.com/Noble-Effeciency13/PIMActivation) for a while, the same activation engine now has a browser companion — for the people on your team who don't want to install PowerShell, the moments when you're on a borrowed machine, or the times you just want a click-through.

Sign in at **<https://portal.pimactivation.com>** and you'll see every PIM eligibility you have across:

- Microsoft Entra ID roles
- Azure Resource roles
- PIM for Groups (member and owner)

…in one combined table, with the per-role policy matrix already resolved (justification, ticket, MFA, auth context, approval, max duration). Bulk-activate, save the combinations you reuse as **profiles**, and watch the active-roles surface count down to expiry in real time.

## What's in 1.0.0

A few of the things I'm most pleased to ship:

- **Bulk activation across all three planes in a single operation**, with Conditional Access auth-context step-up handled mid-flight and the acquired claims threaded into every subsequent request.
- **Activation profiles** — name a set of roles plus a default justification, ticket, and duration; activate the lot in two clicks next time.
- **Strict CSP and tokens-in-`sessionStorage`-only.** No backend, no proxy, no telemetry. Every privileged call goes from your browser straight to Microsoft Graph or Azure Resource Manager.
- **One-click self-hosting** via the included Bicep template, so you can run the portal in your own tenant on Azure Static Web Apps if you'd rather.

The full feature list is in the [CHANGELOG](https://github.com/Noble-Effeciency13/PIMActivation-Portal/blob/main/CHANGELOG.md).
